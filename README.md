# نرم‌افزار حسابداری فروشگاه (دسکتاپ، سبک)

برنامهٔ ویندوزی/لینوکسی با **پایتون خالص + SQLite**؛ تنها وابستگی اجباری `openpyxl` (برای Excel) است.
رابط کاربری فارسی و راست‌چین، تاریخ شمسی، بدون نیاز به اینترنت (به‌جز اتصال ووکامرس/پیامک/لایسنس).

## اجرا
```bash
pip install -r requirements.txt
python main.py            # پنجرهٔ بومی اگر pywebview نصب باشد، وگرنه مرورگر پیش‌فرض
python -m unittest discover -s tests -t .   # اجرای تست‌ها
```
داده‌ها: ویندوز `%APPDATA%\AccSoft`، لینوکس `~/.local/share/AccSoft` (دیتابیس، تصاویر، کلید رمزنگاری). **از این پوشه پشتیبان بگیرید.**

## لایسنس و فروش از طریق webakery.ir
لایسنس یک رشتهٔ امضاشده با **Ed25519** است؛ برنامه فقط کلید عمومی دارد و **بدون کلید خصوصی شما نمی‌توان لایسنس ساخت**.
1. یک‌بار: `python tools/license_tool.py genkey` ← `license_private.key` (محرمانه، در گیت نیست) و کلید عمومی در `accsoft/pubkey.py`. تا این کار انجام نشود، فعال‌سازی غیرممکن است (امن به‌صورت پیش‌فرض). **کلید خصوصی را گم نکنید؛ بدون آن نمی‌توانید لایسنس جدید بدهید.**
2. صدور: `python tools/license_tool.py issue --plan 12m --name "نام مشتری" --mid <شناسهٔ دستگاه مشتری>`
3. پلن‌ها: `lifetime`، `3m`، `6m`، `12m`.

**قرارداد سمت سایت وبیکری** (باید در سایت پیاده شود؛ به سایت شما دسترسی ندارم):
- دکمهٔ «پرداخت» برنامه، کاربر را به `https://webakery.ir/?product=accsoft&plan=<plan>&mid=<machine_id>` می‌برد.
- پرداخت با **زیبال** باید سمت سرور سایت انجام شود (مرچنت‌کد هرگز در برنامهٔ دسکتاپ قرار نگیرد). پس از تأیید پرداخت، سایت لایسنس را صادر و به کاربر نشان می‌دهد.
- اختیاری، دریافت خودکار: `GET https://webakery.ir/api/accsoft/license?order=<کد سفارش>&mid=<machine_id>` ← `{"license": "<کد>"}`.

## امنیت (و محدودیت‌های صادقانه)
- سرور فقط روی `127.0.0.1` گوش می‌دهد؛ بررسی Host/Origin (ضد DNS-rebinding)، توکن CSRF، کوکی HttpOnly+SameSite=Strict، CSP سخت‌گیر برای اسکریپت‌ها.
- رمز با PBKDF2-SHA256 (۲۴۰هزار تکرار)، قفل ۵ دقیقه‌ای پس از ۵ تلاش ناموفق.
- همهٔ کوئری‌ها پارامتری؛ خروجی HTML escape می‌شود؛ Excel در برابر formula-injection ایمن شده؛ آپلود تصویر با بررسی امضای فایل.
- کلیدهای ووکامرس/پیامک روی دیسک رمز می‌شوند (کلید در `secret.key` کنار دیتابیس) و هرگز به UI برنمی‌گردند.
- **هیچ نرم‌افزار دسکتاپی ۱۰۰٪ کرک‌ناپذیر نیست.** لایسنس امضاشده، تشخیص برگرداندن ساعت و اتصال به شناسهٔ دستگاه، جعل ساده را سخت می‌کنند؛ ولی کسی که خود برنامه را patch کند می‌تواند بررسی را دور بزند. برای سخت‌تر کردن: ساخت با Nuitka یا PyArmor، امضای کد (Code Signing) و بررسی آنلاین دوره‌ای لایسنس.
- رمزنگاری اسرار در برابر کاربر دارای دسترسی ادمین به همان کامپیوتر محافظت نمی‌کند.

## ساخت فایل exe (ویندوز)
`build.bat` ← `dist\AccSoft.exe`. این‌جا فقط روی لینوکس تست شده؛ ساخت ویندوز را یک‌بار خودتان امتحان کنید.

## هنوز انجام نشده / محدودیت‌ها
- محصولات متغیر (variable) ووکامرس همگام نمی‌شوند؛ ارسال تصویر محصول **به** سایت پشتیبانی نمی‌شود.
- فقط یک کاربر مدیر؛ فاکتور خرید/تأمین‌کننده و بدهکار-بستانکار/چک ندارد.
- PDF از پنجرهٔ چاپ ساخته می‌شود (نه تولیدکنندهٔ PDF داخلی) تا حروف فارسی درست بماند و برنامه سبک بماند.
- اتصال به ووکامرس/پیامک/وبیکری روی سایت واقعی تست نشد (با شبیه‌ساز تست شده)؛ پیش از استفادهٔ جدی یک سفارش و یک پیامک آزمایشی بزنید.
