# نرم‌افزار حسابداری فروشگاه (دسکتاپ، سبک)

برنامهٔ ویندوزی/لینوکسی با **پایتون خالص + SQLite**؛ تنها وابستگی اجباری `openpyxl` (برای Excel) است.
رابط کاربری فارسی و راست‌چین، تاریخ شمسی، بدون نیاز به اینترنت (به‌جز اتصال ووکامرس/پیامک/لایسنس).

## اجرا
```bash
pip install -r requirements.txt
python main.py            # پنجرهٔ بومی اگر pywebview نصب باشد، وگرنه مرورگر پیش‌فرض
python -m unittest discover -s tests -t .   # اجرای تست‌ها
```
داده‌ها: ویندوز `%APPDATA%\AccSoft`، لینوکس `~/.local/share/AccSoft` (دیتابیس، تصاویر، کلید رمزنگاری). **از این پوشه پشتیبان بگیرید.**

## لایسنس عمومی: هر محصول یا افزونه بدون کدنویسی
هر لایسنس یک رشتهٔ امضاشده با **Ed25519** برای یک «محصول» است (برنامهٔ اصلی `accsoft` یا هر افزونه). برنامه فقط کلید عمومی دارد و **بدون کلید خصوصی شما نمی‌توان لایسنس ساخت**.

**راه‌اندازی (یک‌بار):** `python tools/license_admin.py` ← رمز پنل را بگذارید ← «ساخت کلید». فایل `license_private.key` را **پشتیبان بگیرید و منتشر نکنید**؛ بدون آن لایسنس جدید نمی‌توانید بدهید. سپس برنامه را بسازید (کلید عمومی در `accsoft/pubkey.py` نوشته شده است).

**پنل مدیریت لایسنس** (`python tools/license_admin.py`، فقط روی کامپیوتر خودتان):
- **محصولات و پلن‌ها:** محصول/افزونهٔ جدید (شناسه، نام، روز آزمایشی) و پلن‌هایش (عنوان، مدت ماه یا مادام‌العمر، قیمت) با فرم اضافه می‌شود؛ بدون تغییر کد.
- **صدور لایسنس:** محصول و پلن را انتخاب، نام مشتری و (توصیه‌شده) شناسهٔ دستگاه او را وارد کنید ← کد لایسنس. می‌توانید «ویژگی‌ها» (feature) هم داخل لایسنس بگذارید.
- **لایسنس‌های صادرشده:** جست‌وجو، کپی کد، **ابطال** (مثلاً در صورت بازپرداخت یا سوءاستفاده).
- **انتشار کاتالوگ:** با افزونهٔ وردپرس (بخش زیر) خودکار انجام می‌شود؛ برنامه‌ها با «به‌روزرسانی کاتالوگ» آن را از `https://webakery.ir/wp-json/accsoft/v1/catalog` می‌گیرند. کاتالوگ امضا دارد و نسخهٔ قدیمی‌تر پذیرفته نمی‌شود (ابطال‌ها برنمی‌گردند).
- خط فرمان (برای اتصال بعدی به سایت): `python tools/license_admin.py issue --product accsoft --plan 12m --name "علی" --mid <شناسه>`

**افزونه‌ها:** پوشهٔ `<پوشهٔ داده>/plugins/<id>/` با `manifest.json` (`id`, `name`, `product` = شناسهٔ محصول لایسنس‌دار، `entry`, `menu`, `perm`) و اختیاری `plugin.py` (تابع `register(api)` برای ثبت مسیر API) و `static/`. افزونه فقط با لایسنس معتبر همان محصول اجرا می‌شود و با اتمام لایسنس درخواست‌هایش ۴۰۲ می‌گیرد. **کد افزونه با همهٔ دسترسی‌های برنامه اجرا می‌شود؛ فقط افزونهٔ قابل‌اعتماد نصب کنید.**

**سمت سایت وبیکری — افزونهٔ وردپرس `wordpress-plugin/accsoft-license/`:**
پوشه را زیپ و در وردپرس نصب/فعال کنید (PHP ≥ 7.4 با افزونهٔ sodium). فعال‌سازی، جدول‌ها و صفحهٔ «پیشخوان لایسنس» (`/accsoft-panel/`، شورت‌کد `[accsoft_dashboard]`) را می‌سازد.
- **پنل مدیریت** (منوی «لایسنس AccSoft»): نمای کلی/درآمد، محصولات و پلن‌ها (افزودن محصول/افزونه/پلن بدون کدنویسی)، لایسنس‌ها (جستجو، صدور دستی، ابطال/بازگردانی)، سفارش‌ها، تنظیمات (مرچنت زیبال، سقف انتقال، کلید).
- **پیشخوان مشتری:** ورود با حساب وردپرس؛ خرید (زیبال)، دیدن/کپی کد لایسنس، تمدید، انتقال به سیستم جدید (کد قبلی باطل می‌شود).
- **کلید:** ۶۴ نویسهٔ seed را (همان `license_private.key` پنل محلی، یا کلید جدید از تب تنظیمات) در `wp-config.php` بگذارید: `define('ACCSOFT_SEED_HEX','...');` — در پایگاه داده ذخیره نمی‌شود. کلید عمومی را در `accsoft/pubkey.py` بگذارید و برنامه را دوباره بسازید. از seed پشتیبان بگیرید.
- **API برنامه:** `GET /wp-json/accsoft/v1/catalog` و `GET /wp-json/accsoft/v1/license?order=<کد>&mid=<شناسه>` (محدودیت تعداد درخواست دارد). فقط سفارش پرداخت‌شده با شناسهٔ سیستم مطابق، کد را برمی‌گرداند.
- پرداخت زیبال سمت سرور تأیید می‌شود (verify + مطابقت مبلغ + صدور فقط یک‌بار). مبلغ‌ها تومان‌اند و به ریال تبدیل می‌شوند.
- محدودیت: ابطال/انتقال وقتی در برنامه اعمال می‌شود که کاتالوگ را به‌روز کند (لایسنس آفلاین است). امضای PHP با تست سازگاری با پایتون بررسی شده، ولی خود افزونه روی وردپرس واقعی تست نشده.
> **فایل/مشخصات لایسنس شما:** قالب بالا را طوری نوشته‌ام که فقط یک ماژول (`accsoft/licensing.py`) درگیر است. هر فایل یا قراردادی از سیستم لایسنس خودتان بدهید، همان را هماهنگ می‌کنم.

## کاربران و نقش‌ها
مدیر، حسابدار، فروشنده، انباردار. هر مسیر API که در جدول مجوزها (`accsoft/access.py`) نباشد **فقط برای مدیر** است (deny-by-default). غیرفعال/حذف‌کردن کاربر نشستش را فوراً قطع می‌کند؛ همیشه حداقل یک مدیر فعال می‌ماند؛ ورود، ابطال فاکتور، تغییر قیمت گروهی و مدیریت کاربران در «گزارش رویدادها» ثبت می‌شود.

## خرید، تأمین‌کننده و حساب‌ها
فاکتور خرید موجودی را زیاد و «قیمت خرید» را به‌صورت **میانگین موزون** به‌روز می‌کند. فروش «اعتباری» (نسیه) با پیش‌پرداخت، مشتری را بدهکار می‌کند؛ خرید با پرداخت ناقص، ما را بدهکار تأمین‌کننده. بخش «حساب‌ها» بدهکاران/بستانکاران، ثبت دریافت/پرداخت و صورت‌حساب با مانده تجمعی دارد. سود در گزارش‌ها به‌صورت تعهدی (روز فروش) حساب می‌شود، نه روز دریافت پول.

## ووکامرس: محصول متغیر و تصویر
- محصولات **متغیر** با همهٔ تنوع‌ها دریافت می‌شوند؛ هر تنوع قیمت/موجودی/SKU خودش را دارد، جدا فروخته می‌شود و قیمت/موجودی‌اش به همان تنوع در سایت برمی‌گردد. سفارش‌های سایت با `variation_id` به تنوع درست وصل می‌شوند. ساخت محصول/تنوع متغیر جدید از داخل برنامه پشتیبانی نمی‌شود (فقط ساده).
- **ارسال تصویر** از طریق REST وردپرس (`/wp/v2/media`) با «نام کاربری + رمز برنامه» (Application Password) انجام می‌شود، چون کلید ووکامرس اجازهٔ آپلود ندارد. تصاویر تغییرکرده در «ارسال به سایت» می‌روند؛ خطای تصویر مانع ارسال قیمت/موجودی نمی‌شود.

## امنیت (و محدودیت‌های صادقانه)
- سرور فقط روی `127.0.0.1` گوش می‌دهد؛ بررسی Host/Origin (ضد DNS-rebinding)، توکن CSRF، کوکی HttpOnly+SameSite=Strict، CSP سخت‌گیر برای اسکریپت‌ها.
- رمز با PBKDF2-SHA256 (۲۴۰هزار تکرار)، قفل ۵ دقیقه‌ای پس از ۵ تلاش ناموفق.
- همهٔ کوئری‌ها پارامتری؛ خروجی HTML escape می‌شود؛ Excel در برابر formula-injection ایمن شده؛ آپلود تصویر با بررسی امضای فایل.
- کلیدهای ووکامرس/پیامک روی دیسک رمز می‌شوند (کلید در `secret.key` کنار دیتابیس) و هرگز به UI برنمی‌گردند.
- **هیچ نرم‌افزار دسکتاپی ۱۰۰٪ کرک‌ناپذیر نیست.** لایسنس امضاشده، تشخیص برگرداندن ساعت و اتصال به شناسهٔ دستگاه، جعل ساده را سخت می‌کنند؛ ولی کسی که خود برنامه را patch کند می‌تواند بررسی را دور بزند. برای سخت‌تر کردن: ساخت با Nuitka یا PyArmor، امضای کد (Code Signing) و بررسی آنلاین دوره‌ای لایسنس.
- رمزنگاری اسرار در برابر کاربر دارای دسترسی ادمین به همان کامپیوتر محافظت نمی‌کند.

## ساخت فایل exe (ویندوز)
`build.bat` ← `dist\AccSoft.exe`. این‌جا فقط روی لینوکس تست شده؛ ساخت ویندوز را یک‌بار خودتان امتحان کنید.

## هنوز انجام نشده / محدودیت‌ها
- ساخت محصول/تنوع متغیر جدید از داخل برنامه؛ محصولات گروهی/خارجی/اشتراکی ووکامرس.
- فاکتور برگشت از فروش/خرید، چک و اقساط؛ حذف فاکتور فروش که پرداخت (دریافت) دارد، مانده مشتری را منفی (بستانکار) می‌کند.
- PDF از پنجرهٔ چاپ ساخته می‌شود (نه تولیدکنندهٔ PDF داخلی) تا حروف فارسی درست بماند و برنامه سبک بماند.
- اتصال به ووکامرس/وردپرس/پیامک/وبیکری روی سرویس واقعی تست نشد (با شبیه‌ساز تست شده)؛ پیش از استفادهٔ جدی یک نمونهٔ آزمایشی بزنید.
- ساخت exe فقط برای ویندوز و روی ویندوز؛ این‌جا تست نشده.
